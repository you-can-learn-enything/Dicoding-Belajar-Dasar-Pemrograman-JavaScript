# Pengertian Function
Apa itu Function?
Function adalah blok kode yang dirancang untuk melakukan tugas tertentu. Function membantu kita mengorganisasi kode agar lebih modular, mudah dibaca, dan dapat digunakan kembali (reusable). Dengan menggunakan function, kita dapat menghindari pengulangan kode yang sama di berbagai tempat.


// Definisi function
function namaFunction(parameter1, parameter2) {
    // Blok kode yang akan dijalankan
    return parameter1 + parameter2; // Contoh: mengembalikan hasil penjumlahan
}

// Memanggil function
let hasil = namaFunction(5, 3); // Output: 8
console.log(hasil);

Struktur Dasar Function (Contoh dalam JavaScript)
Penjelasan:

Definisi Function: Function didefinisikan menggunakan kata kunci function, diikuti dengan nama function, parameter (opsional), dan blok kode.
Parameter: Input yang diberikan ke function untuk diproses.
Return: Nilai yang dikembalikan oleh function setelah selesai menjalankan tugasnya.
Pemanggilan Function: Function dipanggil dengan menyebut namanya dan memberikan argumen (nilai untuk parameter).
Manfaat Function
Reusability: Kode dapat digunakan kembali tanpa menulis ulang.
Modularitas: Membagi kode menjadi bagian-bagian kecil yang lebih mudah dikelola.
Meningkatkan Readability: Kode lebih mudah dipahami karena setiap function memiliki tugas spesifik.
Debugging Lebih Mudah: Kesalahan lebih mudah dilacak karena kode terorganisasi.
